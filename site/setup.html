Set up the reader

The board can’t see the stats page by itself: browsers keep sites walled off from each other. A small reader runs in the stats tab and passes what it reads to the board window on the same computer. Pick one way to start it.

Which one? Start with the bookmark: nothing to install. If clicking it shows “blocked”, the console paste always works. Tampermonkey is the hands-free option if the computer lets you add extensions.

1 · Bookmark button No install. Best for a work computer.

  1. Show the bookmarks bar: Ctrl+Shift+B.
  2. Drag this button onto the bar: Pop board
  3. On the stats page, after Accept & Continue, click the bookmark once. A Pop board bar appears at the bottom-right.

Can’t drag? Right-click the bookmarks bar → Add page, name it Pop board, and paste the copied code as the URL.

2 · Paste into the console If bookmarks are locked, or the bookmark shows “blocked”.

  1. Click Copy reader code:
  2. On the stats page press F12 (or Ctrl+Shift+J) and open Console.
  3. If Chrome warns about pasting, type allow pasting and press Enter first.
  4. Paste with Ctrl+V, press Enter, then close the console.

You’ll repeat this each time you open or reload the stats page.

3 · Tampermonkey Starts by itself every time you open a stats page. Needs a browser extension.

  1. Add Tampermonkey from your browser’s extension store: the Chrome Web Store in Chrome, or Edge Add-ons in Edge. If the store says the extension is blocked by your organization, stop here and use the bookmark instead.
  2. Let it run scripts. Browsers now keep this off until you turn it on:
    • Chrome 138 or newer: click the puzzle-piece Extensions icon, then the ⋮ menu next to Tampermonkey → Manage extension. Turn on Allow User Scripts.
    • Older Chrome, or Edge: type chrome://extensions (Edge: edge://extensions) in the address bar and turn on Developer mode.
    Not sure which Chrome you have? Do the first one; if there’s no Allow User Scripts switch, do the second.
  3. Install the reader script: Install reader script Tampermonkey opens its own install page. Click Install.
  4. Check it: open or reload any StatBroadcast stats page. The Pop board bar appears at the bottom-right by itself, and the Tampermonkey icon shows a 1.

Updates: Tampermonkey checks this site for new versions on its own. To update right away, open the Tampermonkey menu → Check for userscript updates. The board tells you when the stats tab is running an older reader.

Nothing happens on the stats page? Open the Tampermonkey menu on that page. If it says scripts are disabled, step 2 isn’t done; if Stat Pop Board reader is listed but switched off, switch it on and reload.

Install by hand instead (if the install button doesn’t open Tampermonkey)
  1. Tampermonkey menu → Create a new script, select everything in the editor and delete it.
  2. Paste the script below, then File → Save.

Test it before a match

  1. Open the board and click Try the practice page. It opens a stand-in stats page that replays MSU vs Idaho; the reader starts there by itself.
  2. To test your bookmark: open the practice page in manual mode, click your Pop board bookmark, then click Open board in the bar that appears.
  3. To test on the real StatBroadcast site before game time: paste the stats link of any finished match into the board, start the reader there, and open Reader check. If it says Reading OK and lists both teams’ players, you’re set. If not, click Copy for Claude and send it.

The practice page’s layout is a guess at StatBroadcast’s, so it tests your setup, not the real page. On game day, Reader check on the board shows exactly what was read from the real page.

What it reads: the score in the stats tab’s title, the box-score tables, and new play-by-play lines. It sends them only to the board window on this computer. Nothing goes to a server; your impact-player picks and hidden players are saved in this browser.
